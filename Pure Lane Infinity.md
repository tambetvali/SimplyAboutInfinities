# Simple principles

Mathematically, first-order integral can show:
- If linear value is built on 0-th octave, 0th integral, 1-to-1 mapping, linear 1D:
  - It does not know in infinity. O-notation is an example: O(n + n^2).
- If exponent value is built on 1-th octave, 1th integral, 1-to-2 mapping, exponential 2D:
  - One point change here is *change into every point which follows*.
  - If this number is literal and balanced:
    - One can show in digits I, the mathematical real-world change *to future and past*, relative to this growth factor further and back.
      - Laegna geometry does this easily, straight mapping.
      - Creating diagonal line from zero to max growth, in exponential scale range so that it's outwards-collapse becomes collapsing;
        - Adding digits, we get deeper and deeper in depth of locality and totality, from both viewpoints.
